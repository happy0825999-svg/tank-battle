# 坦克大战 (Battle City)

纯 HTML5 Canvas 实现的经典坦克大战复刻 —— 单文件、零依赖,双击 `index.html` 即可游玩。

## 玩法

- 守护底部的基地 🦅,消灭每关 **20 辆**敌军坦克
- 基地或你的坦克全部被摧毁则游戏结束
- 关卡递增,敌军速度逐关提升,分数无上限

## 特性

- 🎮 经典玩法:砖墙可破坏、钢墙坚不可摧、水面阻挡移动、树林遮挡视野
- 👾 4 种敌军:普通 / 快速 / 火力 / 重型(3 点护甲,颜色随血量变化)
- 🎁 5 种道具(击毁敌军随机掉落):
  - ⭐ 火力 —— 升级子弹(最多 3 级,3 级可击穿钢墙)
  - 💣 手雷 —— 清屏
  - ➕ 加命 —— 增加 1 条生命
  - 🛡 护盾 —— 8 秒无敌
  - ⏱ 冻结 —— 敌军停止行动 5 秒
- 🔊 Web Audio 实时合成音效(无需音频文件)
- 📱 支持触屏虚拟按键,手机上也能玩
- 🏆 本地最高分记录

## 操作

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` / `WASD` | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 |
| `Enter` | 开始 / 重新开始 |

## 运行

直接双击 `index.html`,或启动本地服务器:

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术

- HTML5 Canvas 像素渲染(208×208 内部分辨率,自动放大)
- 原生 JavaScript,固定时间步游戏循环
- 无任何第三方依赖
